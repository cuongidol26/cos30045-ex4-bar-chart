# Exercises 4.3 to 4.7 D3 bar chart

Horizontal bar chart of the number of TV models per brand (brands with 20 or more models).

- `js/main.js`: loads `data/tvBrandCount.csv`, sorts it, draws bars with `scaleLinear` and `scaleBand`, and adds brand and value labels.
- Run with VS Code Live Server (d3.csv needs a web server).

GenAI use: see the separate GenAI declaration submitted on Canvas.
